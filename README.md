# 蓝牙巡线小车（Bluetooth Patrol Car）

基于 STC8H8K64U 的四轮小车：手机蓝牙遥控 + 红外自动巡线，带低电报警与超声波近距保护。

## 硬件平台

| 项目 | 说明 |
|---|---|
| MCU | STC8H8K64U（8051 内核，1T，64KB Flash / 8KB XRAM） |
| 主频 | 24 MHz（内部 IRC） |
| 实时内核 | RTX51 Tiny 2.02（Timer0 节拍，5 ms/tick，时间片 25 ms） |
| 开发环境 | Keil μVision 5 + PK51，LARGE 内存模型 + 浮点库 |
| 下载工具 | STC-ISP |

## 外设与引脚

| 模块 | 引脚 | 说明 |
|---|---|---|
| 调试串口 UART1 | P3.0 / P3.1 | 115200，printf 输出 |
| 蓝牙串口 UART2 | P1.0 / P1.1 | 115200，接蓝牙模块 |
| 红外巡线 | P0.1 / P0.2 / P0.3 | 高电平表示压到黑线 |
| 按键 | P0.5 | 切换巡线模式 |
| 指示灯 | P0.7 / P5.2 | 低电闪烁、A 键翻转 |
| 蜂鸣器 | P3.4 | PWMB 通道 8 |
| 电池检测 | P1.3（ADC_CH3） | 分压比 6.1 |
| 超声波 | TRIG P4.7 / ECHO P3.3 | 近距保护 |
| 四路电机 | P2.0/2.1、P2.2/2.3、P1.4/1.5、P1.6/1.7 | PWMA 4 路，1 kHz |

## 功能

- **蓝牙遥控**：手机发送 8 字节帧，摇杆控制全向移动，B/C 键原地旋转，A 键翻转指示灯，D 键切换巡线。
- **自动巡线**：三路红外加权平均得到位置偏差，输出左转 / 直行 / 右转，20 tick 采样一次。
- **模式互锁**：巡线开启时手动控制自动让位，开关状态全局唯一。
- **低电报警**：电压低于 10.5 V 时闪灯并播放三声提示音。
- **超声波保护**：巡线时检测到 15 cm 内障碍物立即点刹。
- **调试输出**：UART1 打印运行日志，也可将收到的数据透传给蓝牙。

## 软件结构

| 目录 | 职责 |
|---|---|
| `User/` | 上电初始化、创建任务 |
| `APP/` | 任务与业务决策 |
| `Hardware/` | 器件驱动，只负责动作 |
| `Library/` | STC 官方外设库 |
| `System/` | 内核配置、延时 |
| `Start/` | 寄存器定义 |

任务划分（RTX51 Tiny）：

| ID | 任务 | 周期 | 作用 |
|---|---|---|---|
| 0 | `main_start` | 一次 | 初始化后自删 |
| 1 | `task_key` | 1 tick | 按键扫描（20 ms 消抖） |
| 2 | `task_uart1` | 1 tick | 调试口数据转发 |
| 3 | `task_uart2` | 1 tick | 蓝牙帧解析 |
| 4 | `task_track` | 20 tick | 巡线闭环，按需创建 |
| 5 | `task_ultrasonic` | 100 tick | 近距保护 |
| 6 | `task_battery` | 1 tick | 声光节奏与电量检测 |

## 关键实现

- **巡线开关唯一状态**：`Track_SetEnabled()` / `Track_IsEnabled()` 幂等，按键与蓝牙都只调这两个接口，避免重复创建任务和互锁失效。
- **报警不阻塞**：蜂鸣器用节奏表描述"响什么、响多久"，指示灯用剩余 tick 倒计时，由任务每 tick 推进；驱动层不调用 RTOS、不阻塞任何任务。
- **帧解析容错**：在缓冲区中搜索帧头 `DD 77` 后按定长取帧，粘帧和杂字节都能对齐；按键取边沿，长按只触发一次。
- **速度类型显式**：轮速与摇杆统一使用 `signed char`，并对摇杆值做范围校验，超范围整帧丢弃。

## 蓝牙协议

固定 8 字节：

| 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| 0xDD | 0x77 | X | Y | A | B | C | D |

- `X` / `Y`：有符号补码，范围 −100~100。
- `A`~`D`：非 0 表示按下。

## 编译与烧录

1. Keil 打开 `Project/Project.uvproj`，编译生成 `Project/Output/Project.hex`。
2. STC-ISP 选择 STC8H8K64U，**IRC 频率设为 24 MHz**。
3. 下载后上电，UART1 可查看运行日志。

## 注意事项

- 代码不写时钟寄存器，主频完全依赖下载时的 IRC 设置，设置错误会导致波特率、PWM 频率和系统节拍全部偏移。
- `Hardware/Battery.c` 中 `ADC_VREF` 默认 2.5 V，需按板上实际基准修改，否则电压读数成比例偏差。
- 超声波为巡线时的点刹保护，不是完整避障。
